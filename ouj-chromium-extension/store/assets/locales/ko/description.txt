OUJ 수업 브라우저 (방송대학)

일본 방송대학(The Open University of Japan, OUJ)의 동영상 시청과 학습을 더 편리하고 쾌적하게 만들어 주는 Chrome 확장 프로그램입니다. 일본어·English·한국어·简体中文·繁體中文을 지원하며 브라우저 언어에 맞춰 자동으로 전환됩니다. 다만 OUJ 사이트 자체(과목명·강의 제목)는 일본어입니다.

■ 주요 기능

◆ 동영상 재생 페이지
・이전/다음 강의 링크와 같은 과목의 강의 목록
・재생 속도 조절(과목별로 기억)
・다음 동영상으로 자동 이동(취소 가능한 카운트다운 표시)
・TV/라디오 프로그램 자막 켜기/끄기
・자동 재생, 시작/끝부분 자동 건너뛰기(과목별로 기억)
・배속을 반영한 실제 남은 시간 표시
・화면 속 화면(PIP), 책갈피(재생 위치+메모), 연속 재생이 가능한 "나중에 보기" 목록
・A-B 구간 반복, 취침 타이머, 화면 잠금 방지, 음량 평준화
・미디어 키·잠금 화면 조작(Media Session)
・미리 읽기(버퍼) 길이 설정(최대 10분). 회선이 불안정해도 끊기기 어렵습니다
・시청 상태를 수시로 저장

◆ 과목·동영상 목록
・시청 진행률 막대와 배지, 첫 미시청 강의로 바로 이동하는 "이어보기" 버튼, 수료 페이스 예측
・즐겨찾기 과목(수동 정렬, 고정)

◆ 검색
・검색창에 포커스하면 빠른 필터 패널 표시: 키워드 없이도 연도·과목 선택 가능
・TV/라디오, 자막, 미완료만, 연도·과목 필터, 최근 검색, 정렬

◆ 메뉴
・즐겨찾기, 나중에 보기, 책갈피, 기록, 추천 동영상
・학습 시간(7/30/90일 그래프, 연속 학습일, 일일 목표)
・새 소식, 다크 모드
・표시 옵션: 이 확장 프로그램이 화면에 추가하는 표시를 기능별로 끌 수 있습니다(기록된 데이터는 유지)

◆ 홈 화면
・"이어서 보기" 패널

■ 사용 방법·지원 브라우저
・OUJ 홈 페이지를 북마크해 두면 편리합니다: https://v.ouj.ac.jp/view/ouj/#/navi/home
・iPhone: Orion Browser by Kagi에서 설치를 시도해 보세요 https://apps.apple.com/jp/app/orion-browser-by-kagi/id1484498200
・Android: Quetta 브라우저 https://play.google.com/store/apps/details?id=net.quetta.browser 또는 Yandex Browser https://play.google.com/store/apps/details?id=com.yandex.browser (미검증이므로 동작 보고를 환영합니다)

■ 변경 사항 (2026.9.30)
・일본어·English·한국어·简体中文·繁體中文을 지원합니다. 브라우저 언어에 맞춰 자동으로 전환되며, 설정에서 직접 선택할 수도 있습니다.
・Chrome 웹 스토어와 확장 프로그램 목록에 표시되는 이름과 설명도 각 언어로 표시됩니다.

■ 유의 사항
・이 확장 프로그램은 개인이 개발한 것으로 방송대학 공식 제품이 아닙니다.
・사용에 따른 책임은 사용자에게 있습니다.
・개인 정보는 수집하지 않습니다. 즐겨찾기·기록·설정은 브라우저 안에만 저장됩니다.
